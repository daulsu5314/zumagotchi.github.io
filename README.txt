쭈마고치 앱(PWA) 올리는 방법 - GitHub Pages (무료)
주소 목표: https://zumagotchi.github.io/  (계정 이름이 안 들어가요)

[1] GitHub 오른쪽 위 + -> New organization -> Free 선택
    - Organization name: zumagotchi  (이미 있으면 다른 이름)
    - "My personal account" 선택 -> Next -> 초대는 Skip
[2] 조직 화면에서 New repository
    - 이름을 "조직이름.github.io" 로 정확히 (예: zumagotchi.github.io)
    - Public -> Create repository
[3] "uploading an existing file" 클릭
    - 이 폴더 "안의 파일들"을 전부 끌어다 놓기 -> Commit changes
[4] Settings -> Pages -> Branch: main, / (root) -> Save
[5] 1~2분 뒤 https://조직이름.github.io/ 로 열려요

폰에 설치
- 안드로이드(크롬): 주소 열기 -> "앱으로 설치하기" 버튼 (또는 ⋮ -> 홈 화면에 추가)
- 아이폰(사파리): 주소 열기 -> 공유 버튼 -> "홈 화면에 추가"

새 버전으로 바꿀 때
- Add file -> Upload files -> 바뀐 index.html, sw.js 올리기 -> Commit changes
- 폰에서 앱을 완전히 껐다 켜면 새 버전이 적용돼요
